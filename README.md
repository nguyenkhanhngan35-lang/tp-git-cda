# TP Git CDA

## Description

Ce projet est un exercice réalisé dans le cadre de ma formation CDA.

Il permet de découvrir les bases de Git et GitHub :
- création d'un repository
- clonage d'un repository
- création et modification de fichiers
- commit
- push

## Lancer le projet

Cloner le repository :

git clone https://github.com/nguyenkhanhngan35-lang/tp-git-cda.git

Entrer dans le dossier :

cd tp-git-cda

Ouvrir le fichier `index.html` dans un navigateur web.
